# 🎓 내 학점 구하기 (Save My GPA)
건국대학교 일감호를 배경으로 한 현실 반영 대학 생활 서바이벌 회피 게임입니다. 스타듀밸리 감성의 도트 그래픽과 와플래시 게임의 직관적인 UI를 오마주하여 제작되었습니다.

## 🎮 게임 특징
- 학기 기반 시스템: 평시, 시험기간, 방학의 3개 시즌이 순환되며 시즌에 따라 배경, BGM, 아이템 효율이 변화합니다.
  *실시간 스탯 관리: 멘탈이 0이 되면 GPA(학점)가 깎이며, 학점이 0.0이 되면 즉시 제적(Game Over)됩니다. 4학년 2학기까지 학점을 사수하여 무사히 졸업하는 것이 목표입니다.
- 명예의 전당: 졸업 성공 시 이름(이니셜)을 입력하여 역대 고득점자 랭킹에 등록할 수 있습니다.

## ⌨️ 조작 방법
- 이동: 키보드 방향키 (상, 하, 좌, 우)
- 게임 시작: `SPACE` 키 (시작 화면 및 도움말 화면)
- 도움말 열기/닫기: `H` 키 또는 `ESC` 키
- 이름 입력 완료: 이름 입력 창에서 `ENTER` 키
